# 13 — Installers & Auto-Update

## Artifacts per release

| OS | Artifact | Tooling |
|---|---|---|
| Windows 10+ | `.msi` (x64), optional `.zip` portable | WiX v4 (`packaging/windows/installer.wxs`), codesign with org cert |
| macOS 11+ | `.dmg` (universal: arm64 + x86_64) | `create-dmg` + `tauri bundle`, notarization (Developer ID) |
| Linux | `.AppImage` (universal) + `.deb` (Ubuntu 20.04+) + `.rpm` (Fedora) + AUR + Homebrew tap | tauri bundler + `packaging/debian/` + `packaging/aur/` + `packaging/homebrew/` |
| Android | `.aab` (Play) + `.apk` (GitHub/F-Droid) | Gradle `bundleRelease`, F-Droid build recipe (reproducible) |

All host installers:
- include the **WinTun driver** (Windows) with silent install,
- register the `unitether` CLI on PATH (optional component),
- add `netdev` group hint (Linux) / no sudo required paths (macOS utun).

## winget / brew manifests
- `packaging/windows/winget/unilink.yaml` — submitted to
  `winget-pkgs` post-1.0 (CI pushes on tag).
- `packaging/homebrew/unitether.rb` — bottle per-arch.

## Auto-update
- **Host**: Tauri updater (minisign-signed artifacts) →
  `https://updates.unitether.org/latest` (static, CDN). Manual
  "check for updates" + optional silent background check; **never
  auto-installs** without user action (trust model).
- **Android**: Play internal track + GitHub Releases; F-Droid
  builds are reproducible (no remote code).
- Update metadata: `packaging/update/latest.json` (version, sha256,
  minisign sig, release notes, platform list) — generated by
  `release.yml`.

## Rollout
Canary (10 %) → stable, per-channel (`channel` field in metadata).
Rollback = re-point metadata (artifacts are immutable, versioned paths).
